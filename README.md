# Track your expenses in the terminal.

## SETUP
### Run this in the cloned repo's direcotory
- Allow setup script to be executed
```
chmod +x ./setup.sh
```
- Run the setup script
```
./setup.sh
```

## USAGE
- `exptrack [NAME] [AMOUNT]` to add new expense to the list
- `exptrack --list` to get a table of all expenses
- `exptrack --delete [NUMBER]` to delete a record with a given number
- `exptrack --total` to get a total of all expenses
